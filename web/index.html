METHOD & LIMITS

A plan is a hypothesis. Measure it.

Read access paths

ALL means a full table scan; index means a full index scan. Compare the chosen key with possible keys, filter estimates and table size before deciding whether an index is missing.

Keep costs comparable

Optimizer cost is not milliseconds. Root cost is shown separately and never summed with child costs. Compare the same query, engine version, data and settings. MySQL and MariaDB costs are not interchangeable.

Separate actual measurements

MariaDB ANALYZE FORMAT=JSON may include r_rows and r_loops; these are displayed separately. ANALYZE executes the query. MySQL TREE output and JSON format version 2 are not supported here.

Inputs are held only in memory. No plan, SQL or file is uploaded or saved automatically. CoolCode's aggregate visit counter runs independently and does not receive your plan. Downloaded reports contain your plan details.
